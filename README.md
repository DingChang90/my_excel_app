# ⚡ Excel 中奖金额拆分工具 (Excel Winner Amount Splitter)
> 🚀 在线直接体验：**https://myexcelapp.streamlit.app/**

一个基于 Python & Streamlit 开发的轻量级 Web 数据处理工具。自动识别表格中的「中奖金额」列，将超过指定阈值的金额切分为多行数据，并原样复制其他关联列信息，完美解决人工拆分繁琐、易错的问题。





---

## 🌟 核心功能
- **智能列定位**：自动读取上传 Excel 的第一个 Sheet，精准识别标题为 `中奖金额` 的列。
- **自定义拆分阈值**：支持任意金额阈值设置（如 200 元），超过阈值自动切分，剩余金额精确保留（绝不留 0 元行）。
- **数据关联复用**：拆分生成的新行紧跟在原行下方，原数据的其他所有字段（如姓名、订单号、时间等）自动完整复制。
- **内存流式处理**：全过程基于内存操作，无需写磁盘，保障多用户并发使用时的**数据隔离与隐私安全**。
- **即时预览与下载**：处理完成后提供前 10 行结果实时预览，支持一键导出标准 `.xlsx` 文件。

## 💡 拆分逻辑示例
**输入条件**：拆分阈值设为 **`200`** 元。

#### 拆分前：
| 订单号 | 用户名 | 中奖金额 | 中奖时间 |
| :--- | :--- | :--- | :--- |
| A001 | 张三 | **414** | 2026-10-08 |
| A002 | 李四 | **400** | 2026-10-08 |
| A003 | 王五 | **150** | 2026-10-08 |

#### 拆分后：
| 订单号 | 用户名 | 中奖金额 | 中奖时间 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| A001 | 张三 | **200** | 2026-10-08 | *拆分第 1 份* |
| A001 | 张三 | **200** | 2026-10-08 | *拆分第 2 份* |
| A001 | 张三 | **14** | 2026-10-08 | *拆分第 3 份（余数）* |
| A002 | 李四 | **200** | 2026-10-08 | *拆分第 1 份* |
| A002 | 李四 | **200** | 2026-10-08 | *拆分第 2 份（整除不留 0 元）* |
| A003 | 王五 | **150** | 2026-10-08 | *未超阈值，保持原样* |
